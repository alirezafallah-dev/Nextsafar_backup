## 📋 بخش‌های اضافی و وضعیت حذف

### 🔴 حذف شده (مرحله ۰.۳ - فاز آماده‌سازی)

| فایل | دلیل حذف | جایگزین |
|------|---------|---------|
| `inc/auth/otp.php` | احراز هویت در وردپرس ممنوع | لاراول Auth Module |
| `inc/auth/google.php` | OAuth در وردپرس ممنوع | لاراول Auth Module |
| `inc/auth/session.php` | مدیریت سشن در وردپرس ممنوع | لاراول Sanctum |

**وضعیت:** غیرفعال شده با Feature Flag (کد هنوز موجود است ولی اجرا نمی‌شود)

## 🚨 قوانین حذف امن

1. **هرگز حذف ناگهانی نکن** - اول غیرفعال کن، بعد حذف
2. **Feature Flag** - همه بخش‌های اضافی باید با سوئیچ خاموش شوند
3. **جایگزین لاراولی** - قبل از حذف، جایگزین باید ساخته شده باشد
4. **تست کامل** - بعد از هر غیرفعال‌سازی، تست کنید
5. **بکاپ** - قبل از حذف نهایی، بکاپ بگیرید
